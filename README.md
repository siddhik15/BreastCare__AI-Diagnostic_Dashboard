# 🎗️ Breast Cancer AI Diagnostic System

An AI-powered web application built with **Streamlit** and **Machine Learning** to assist in the early prediction of breast cancer using the **Wisconsin Breast Cancer Dataset**. The application provides an interactive dashboard for prediction, model evaluation, dataset exploration, and patient risk analysis.

---

## 📌 Features

- 🩺 Breast Cancer Prediction using Random Forest Classifier
- 📊 Interactive Clinical Dashboard
- 📈 Model Performance Visualization
  - ROC Curve
  - Confusion Matrix
  - Accuracy Score
  - Cross Validation Score
- 📂 Dataset Explorer
- 📉 Feature Importance Analysis
- 📝 Professional Diagnostic Report
- 📄 Downloadable PDF Report
- 💗 Clean Pink Medical UI
- ⚡ Fast Predictions using Scikit-learn Pipeline
